# Arrays

This folder contains solutions to common array-based Data Structures and Algorithms (DSA) problems implemented in Python.

## Problems

### 1. Two Sum
**Description:** Find the indices of two numbers in an array whose sum equals a given target.

- **Approach:** Hash Map
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)

---

### 2. Three Sum
**Description:** Find all unique triplets in an array whose sum equals the target.

- **Approach:** Sorting + Two Pointers
- **Time Complexity:** O(n²)
- **Space Complexity:** O(1) (excluding the output list)

---

### 3. Kadane's Algorithm (Maximum Subarray Sum)
**Description:** Find the maximum sum of a contiguous subarray.

- **Approach:** Dynamic Programming (Kadane's Algorithm)
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
